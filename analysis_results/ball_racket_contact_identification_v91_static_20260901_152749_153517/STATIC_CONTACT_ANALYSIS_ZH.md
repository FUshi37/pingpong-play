## 固定底座完整机器人 MJX 位置回放

本轮不从单个入射速度反推高度。每组都从释放至首次碰撞的连续球位置拟合重力—二次阻力状态，并按该组对应的释放位置和速度启动完整机器人 MJX。机器人先保持实物碰撞时的右臂姿态预热 3500 步（0.700 s）。

- 数据范围硬约束：每条录制只选择释放后的第一次撞拍；碰后拟合窗口止于第一次撞拍后 `0.226–0.235 s`，检测到的下一次撞拍位于 `0.255–0.332 s`，最小隔离间隙 `22.6 ms`。后续颠球样本使用数为 `0`。
- 原 MJX 第 700 步底座 z 漂移：`-10.033779 mm`；固定后：`-0.000047 mm`。
- 修复方式：锁定六个基座关节的等式约束，保持 qpos/dof/actuator 布局不变；默认可移动底座训练路径仍可选择不启用。
- 生产 `1.0 ms` 步长逐录制阻尼范围：`0.184383`–`0.420024`，受 3 ms 接触过程的离散相位影响而不收敛；以下候选使用 `0.2 ms` 接触辨识步长。
