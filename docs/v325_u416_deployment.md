# V325 u416 部署适配（2026-11-24）

当前新增独立发布 `fplc_gpu0_v325_u416`，旧 `fplc_gpu0_v325` 继续指向 S15/u14400 的 114D 双网络模型。全局默认仍为 V172；没有迁移 simcode1–10，没有启动实物或 ROS，也没有运行 colcon。`simcode11/COLCON_IGNORE` 保持有效。

2026-11-24 新录制审计追加修复：u416 的策略年龄改为 `native_refresh_clock`（90 Hz 刷新为 0，保持时按 5 ms 累计），而非原始动捕包年龄。原始年龄继续用于 350 ms 有效性检查及记录。部署版本为 `u416_native_age_v2`，模型权重保持不变。之前适配遗漏了这层年龄口径；原函数在统一年龄输入后的算术一致，不能代替年龄生成链的一致。分析见 `analysis_results/v325_u416_negative_y_20261124/REPORT_ZH.md`。

## 使用

```bash
# 配置及模型身份校验，不启动设备
PROBE_CONFIG_ONLY=true POLICY_RELEASE_ID=fplc_gpu0_v325_u416 ./RUN_INTERACTIVE_POLICY_SAFETY_PROBE.sh
# 启动交互网页
POLICY_RELEASE_ID=fplc_gpu0_v325_u416 ./RUN_INTERACTIVE_POLICY_SAFETY_PROBE.sh
```

网页 RL profile 可选择“V325 u416 固定±5° 单MLP (120D，临时版本)”。切换版本、改变观测采样率或外部安全干预后清空状态并要求重新使能发送。

实物外层姿态保护已按 2026-11-24 的追加授权扩大为 ±7°；策略内部投影仍固定 ±5°。此前实物实测姿态超过 ±5° 即停机，与训练仅约束目标姿态的处理不同。

## 120D 观测（下标从 0 开始）

| 列 | 含义 |
| --- | --- |
| 0–71 | 既有 position-only 72D 前缀：q、dq、q_ref 误差、投影后的上次动作、8 点球位置、当前拍姿、8 点缓存刷新年龄、回合目标 XY、是否直接观察到球 |
| 72–95 | 相对当前球位置的 8 点实测位置历史，延迟 0/50/100/150/200/300/400/500 ms |
| 96–103 | 对应训练缓存刷新年龄 / 0.6 s |
| 104–111 | 对应有效性；reset 时未积累的历史无效 |
| 112 | 第 5 次合格起球确认后 `p=sin²(π/2·clip(elapsed/3s,0,1))`；此前为 0 |
| 113 | `clip(72p,0,1)`，第二个时间基函数 |
| 114–115 | 因果风估计 XY / 1.6 m/s |
| 116 | 估计年龄 / 0.6 s；不可用时为 1 |
| 117 | 风估计有效标记 |
| 118–119 | `估计风XY/1.6 × clip((估计风速−1.25)/0.35,0,1)`；112 列为 0 时这两列为 0 |

相对旧 114D，新版替换了 112–113 的“姿态权限”语义，再增加 4D 因果风估计与 2D 强风特征；不能在旧 114D 后简单补 6 个零。

风估计只读取 72–111 的位置差、训练缓存刷新年龄和有效性：用 6 组三点差分，剔除不满足弹道条件的片段，反演训练中的 4 g 球增量阻力模型，以一致的最近方向或稳健 medoid 选择候选。至少两个有效候选、历史达到 250 ms 才有效；风速限制 1.6 m/s，Y≤0。没有实物主动加风也按同一源码计算，不能将仿真真实风、随机起风计划或未来状态直接写入 actor。

这两个起球时间特征不缩放动作，也不改变姿态边界。仿真从真实合格触球标志取得第 5 次时刻；硬件沿用实测球靠拍、上升离拍与估计顶点的合格起球识别。这是明确记录的估计，无法宣称触球时刻与仿真真值完全一致。

- 新增独立选项、120 个观测名称、观测片段和单位；旧 114D 提示与 u416 固定 5° 提示分别显示。

## 验证范围及差异

验证结果和耗时记录见 `recovery_artifacts/v325_u416_adaptation_20261124/validation.json`。包括 1024 条原生训练快照的观测重建、原始源码公式与单 MLP 前向比对、历史/丢帧/复位、固定姿态发布边界、网页切换、启动配置和 CPU mirror 回归。

本次验证不等于实物成功验收，也没有重跑完整 MJX 长时训练评估。训练清单明确标注 provisional、simulation_only=true、normal_path_promoted=false，原综合考核及最终 1200s/99 验收未通过。模型物理配置的球高上界为 1.50 m，不能混用另案 1.55 m 的恢复评估。

已有实物外层球 done 去抖、可配置球范围和 350 ms 丢失保持继续作为部署机制；它们与原生训练终止条件并非逐项相同。此前授权的工作空间外扩也仅作用于实物外层，不修改策略的训练内层投影。

## 留痕及回退

修改前文件、文件哈希、补丁及验证结果保存于 `recovery_artifacts/v325_u416_adaptation_20261124/`。回退脚本默认仅检查：

```bash
python3 recovery_artifacts/v325_u416_adaptation_20261124/rollback.py
# 确定恢复本次修改前的工作区状态时执行
python3 recovery_artifacts/v325_u416_adaptation_20261124/rollback.py --apply
```

脚本遇到后续修改会整体拒绝恢复，避免覆盖新工作；原始模型、录制和此日志保留。也可直接选择旧发布 `POLICY_RELEASE_ID=fplc_gpu0_v325`，无需文件回退。

实物姿态外层扩大为 7° 的追加留痕位于 `recovery_artifacts/v325_u416_real_pose_7deg_20261124/`。仅撤销此次 7° 调整可运行该目录的 `rollback.py`（默认检查，增加 `--apply` 执行）。如需继续回退整个 u416 适配，应先撤销这次追加修改，再使用上一轮回退脚本；哈希冲突保护会阻止跨越后续改动直接覆盖。

年龄口径修复的追加留痕在 `recovery_artifacts/v325_u416_native_age_20261124/`。当前回退须先使用这一目录的 `rollback.py`，再按需撤销上一轮 7° 修改。网页与控制记录会同时保留 `actorSampleAgeS`、`heldRawMeasurementAgeS`、`inputRawMeasurementAgeS`，明确区分策略特征与物理测量年龄。运行中的后端不会热加载，需要重新启动脚本。
